Playing is the same as in v0.1.0. This is the first version built, tested and published by the project's own pipeline on GitHub, with no manual step, and it fixes one message of the `check` command.

## ⬇️ Download

Download **`VRGyroScreen-Setup-v0.1.1.exe`** below and run it. It installs only for your Windows user and does not ask for an administrator password. If you have v0.1.0, it is replaced and your settings are kept.

The installer is not digitally signed yet, so Windows may show a warning before it runs. Choose **More info** and then **Run anyway**.

Step by step, with pictures: [Download and install](https://github.com/scarletmodder/vr-gyro-screen#%EF%B8%8F-download-and-install) (English) or [Baixar e instalar](https://github.com/scarletmodder/vr-gyro-screen/blob/main/README.pt-BR.md) (Português).

## ✅ What you need

- A PC with Windows 11
- A Meta Quest headset (the only headset tested so far)
- [Virtual Desktop](https://www.vrdesktop.net), on the headset and on the PC
- [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases), a free driver that lets programs create a gamepad

## 🔁 What changed

- Fixed: on a computer without the gamepad driver, the `check` command said that a library of the program had failed. It now says that the library is fine and its driver is missing.
- Every pull request now builds the installer, installs it in a temporary folder, runs the installed program's own check and uninstalls it.
- A new version is published automatically when a change that raises the version number reaches the main branch.
- The libraries inside the installer are pinned to the exact versions it was tested with.
